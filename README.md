# MediCare HMS — Django + PostgreSQL SQL-Connected App

This is the final demonstration version for Phase 3.

It uses:

- Django frontend templates
- Django backend views/API endpoints
- PostgreSQL database
- Your original SQL scripts for the schema, indexes, views, sample data, queries and extra functionality
- Raw SQL through `connection.cursor()`

It does **not** use Django ORM-generated hospital tables such as `patients_patient` or `billing_bill`. The running pages read and write the original Phase 3 tables:

- `"Staff"`
- `"Patient"`
- `"Appointment"`
- `"Admission"`
- `"Diagnosis"`
- `"Prescription"`
- `"Medication"`
- `"Laboratory_Test"`
- `"Medical_Aid"`
- `"Billing"`
- `"BillingLog"`
- `"AuditLog"`
- `"Ward"`
- `"Nurse_Ward"`

## Why the folder has more files now

This project is structured as a proper Django app with separate backend modules:

- `accounts/` raw SQL staff login and staff page
- `patients/` raw SQL patient list, detail and create form
- `appointments/` raw SQL appointment list, booking, status update and email notification
- `clinical/` raw SQL diagnosis, prescriptions, medication and lab results
- `wards/` raw SQL ward, nurse assignment and admission pages
- `billing/` raw SQL billing and BillingLog trigger proof
- `reports/` dashboard, SQL query demo, database proof and API JSON endpoints
- `templates/` full Django frontend templates
- `static/` CSS for modern dashboard styling
- `database_scripts/` your original SQL files
- `legacy_reference/` original older ZIPs saved for reference only, not for running

## Run on Mac

Open this folder in VS Code, then run:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
export PATH="/Library/PostgreSQL/18/bin:$PATH"
```

Create the database:

```bash
createdb -U postgres -h localhost -p 5432 hprs_phase3_db
```

If it already exists, that is okay. You can reset it using the schema script.

Run your SQL scripts:

```bash
PGPASSWORD='041213' psql -U postgres -h localhost -p 5432 -d hprs_phase3_db -f database_scripts/01_create_tables_postgresql.sql
PGPASSWORD='041213' psql -U postgres -h localhost -p 5432 -d hprs_phase3_db -f database_scripts/02_indexes_views.sql
PGPASSWORD='041213' psql -U postgres -h localhost -p 5432 -d hprs_phase3_db -f database_scripts/03_sample_data.sql
PGPASSWORD='041213' psql -U postgres -h localhost -p 5432 -d hprs_phase3_db -f database_scripts/05_extra_functionality.sql
```

Run Django:

```bash
DB_NAME=hprs_phase3_db DB_USER=postgres DB_PASSWORD='041213' DB_HOST=localhost DB_PORT=5432 python manage.py runserver
```

Open:

```text
http://127.0.0.1:8000/
```

## Email

By default, email prints in the terminal using Django console email backend.

To send real Gmail emails, run:

```bash
DB_NAME=hprs_phase3_db DB_USER=postgres DB_PASSWORD='041213' DB_HOST=localhost DB_PORT=5432 \
EMAIL_BACKEND='django.core.mail.backends.smtp.EmailBackend' \
EMAIL_HOST_USER='yourgmail@gmail.com' \
EMAIL_HOST_PASSWORD='your_gmail_app_password_without_spaces' \
python manage.py runserver
```

Use a Gmail App Password, not your normal Gmail password.

## What to say in the video

> This project uses Django for the frontend and backend. The PostgreSQL schema is not generated by Django ORM. Our original Phase 3 SQL scripts create the database objects, constraints, indexes, views, sample data and extra functionality. Django connects to those exact PostgreSQL tables using raw SQL queries through the backend. The frontend pages display and update live records from those SQL-created tables.

## Best proof during the video

1. Open `database_scripts/01_create_tables_postgresql.sql`.
2. Show `"Patient"`, `"Staff"`, `"Appointment"`, `"Billing"` table creation.
3. Run/select data in pgAdmin:

```sql
SELECT * FROM "Patient";
SELECT * FROM "Appointment";
```

4. Open the website and show the same patients and appointments.
5. Book a new appointment.
6. In pgAdmin, run:

```sql
SELECT * FROM "Appointment" ORDER BY "AppointmentID" DESC;
```

7. Show the new appointment inserted into the original SQL table.
8. Use SQL Query Demo and Database Proof pages.
